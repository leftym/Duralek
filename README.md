# Duralek

The studio site for Duralek Games, served with GitHub Pages from `main` (root).

- `index.html`: the whole site (fonts in `fonts/`, Alegreya under the SIL Open Font License; images in `img/`).
- `brand/`: logo files and the Google Play developer page images:
  - `duralek-icon-512.png`: developer page icon (512×512)
  - `duralek-play-header-4096x2304.jpg`: developer page header image (4096×2304, under 1 MB)
  - `duralek-logo-horizontal.png` (transparent), `duralek-logo-stacked-cream.png`, `duralek-logo-stacked-dark.png`

The painted art was made with generative tools (Higgsfield).
